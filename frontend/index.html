About Avarixen

Avarixen is a free, browser-based Roblox avatar downloader and 3D exporter. Enter a Roblox username to retrieve the avatar, preview it in interactive 3D, inspect its mesh hierarchy, and export it to OBJ, FBX, GLB, or glTF for 3D modeling and animation workflows.

Features

  • Retrieve any Roblox avatar by username and view its 3D model.
  • Interactive 3D preview with orbit, pan, and zoom.
  • Model hierarchy inspection — browse body parts and accessories.
  • Separate asset handling — export textures and buffers as external files in a ZIP.
  • Export to OBJ, FBX, GLB, and glTF formats.
  • Experimental R6/R15 auto-rigging, with optional extra joints for R6.
  • Mesh subdivision quality presets from Minimal to Extreme.

Supported workflows

Exports are tested with Blender 3.6 and Prisma3D 3.3.5. Import the downloaded OBJ, GLB, glTF, or FBX file into your preferred 3D application for modeling, rigging, and animation.

Frequently Asked Questions

How do I download my Roblox avatar as a 3D model?

Enter your Roblox username, wait for the 3D preview to load, then use the download button. The main button downloads an OBJ (ZIP) bundle; the arrow menu offers GLB, glTF, and FBX.

Can I export Roblox avatars to FBX?

Yes. Choose FBX from the download menu. Avarixen produces a binary FBX 7.4 file, optionally rigged and with separate textures in a ZIP.

Can I use Avarixen with Blender?

Yes. Blender imports OBJ, FBX, GLB, and glTF directly (File ▸ Import). Exports are tested with Blender 3.6.

Can I import exported avatars into Prisma3D?

Yes. Prisma3D can import OBJ, FBX, GLB, and glTF exports. Tested with Prisma3D 3.3.5.

Does Avarixen support R6 and R15?

Yes. Avarixen detects the avatar type and supports both R6 and R15 rigs. R6 also offers an optional "More joints" mode for extra bones.

Do I need to install anything?

No. Avarixen runs entirely in your browser. The hosted demo needs no installation — just open the website.

Can I host Avarixen locally?

Yes. The project runs on Node.js 18+. Clone the repository, install dependencies, configure the Roblox API key, then start the backend and frontend. See the README for setup steps.
